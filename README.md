# 三角洲行动 · 纯 TTK 枪械强度榜
[![CI](https://github.com/AVA-2568/delta-gun-tierlist/actions/workflows/update.yml/badge.svg)](https://github.com/AVA-2568/delta-gun-tierlist/actions/workflows/update.yml)

本榜单回答三个问题：**在给定护甲、弹药与距离下，这把枪击杀对手需要多久（毫秒）**、**这次击杀要花多少哈夫币**，以及**起一把整枪（含核心配件与 180 发备弹）要多少钱**。

| 项 | 说明 |
| :-- | :-- |
| 排序键 | 距离带内平均实战 TTK（`首发扳机延迟 + 击发时刻 + 弹丸飞行时间`） |
| 不参与 | 开镜时间、换弹、命中率修正 |
| 起枪状态 | 每行 = 一个「起枪配置状态 × 一款有价弹」：本体裸枪、本体+官方预装件（官方变体出厂态）、束搜索枚举的改装状态（官方插槽规则 + 强制联动）；同口径同等级的多款有价弹各出一行，缺价弹（市场无价）不参与枚举；仅列出 TTK 有差异的状态，全部一起排名分层 |
| 预装收益 | 该距离带内**本体裸枪 → 本状态**的平均 TTK 缩短量与百分比（`—` 表示本体裸枪行） |
| 起枪成本 | 裸枪价格 = 本体交易行当日价（变体/改装共用本体价）；整枪+180 发备弹 = 裸枪价 + 核心配件价 + 180 × 该行所配弹药单发价（预估；白板裸枪配件价为 0） |
| 距离场 | 0–80 m（官方排行口径），分 4 个距离带，每带独立成榜 |
| 分层 | 带内 TTK 分位数切分 T0–T3，阈值公开；文档 T0 全列、T1 列前 100 行（其余见 `data/榜单/*.json`） |
| 数据版本 | `20261015-bd-balance.1`（dfttk-v3） |

> 实战 TTK = 首发扳机延迟 + 击发时刻 + 弹丸飞行时间。击发时刻：单发/全自动为 `(期望击杀发数 − 1) × 射击间隔`；连发按官方 `sdkTiming` 节拍；多弹丸按扣动扳机发数。飞行时间：`距离 / 原始初速`（不含精校修正）。
> 「纯 TTK」只表示榜单只按 TTK 排序、不合成经济性/操控性权重，不代表剔除飞行时间。

## 方法学与可信度

- **命中分布**：实战情景用 `volume-aim` —— 预瞄点取胸腹交界（1.30 m），弹着点服从以预瞄点为中心的二维高斯（σ_v=0.28 m、σ_h=0.50σ_v），按 1.75 m 正面轮廓积分，躯干按「胸:腹 = 1:2」分界（剑突高度 1.348 m）；逐部位占比：头 9.1% / 胸 19.7% / 腹 40.7% / 上臂 14.2% / 前臂 5.4% / 大腿 10.7% / 小腿 0.2%。推导与参数见 `tools/derive_hit_probabilities.py` 与 [ADR-0008](docs/adr/0008-volume-aim-hit-distribution.md)；官方 `default` 预设（头 17.2% / 腿 14.2%）保留在表内作对照、不发布。
- **期望击杀发数**：按官方伤害规则（血量 100、单弹匣不换弹、碎甲按剩余耐久比例、距离衰减同时作用于肉伤与护甲）逐位复现官方 `candidateMetrics`，**3774 个样本点**中，逐位一致 1443、|Δ|≤1e-9 1546、≤1e-5 743、≤1e-2 39、>1e-2 3（最差 0.02449 发）；785 个残余偏差点经白盒对拍证实为官方上游数据自相矛盾所致（记录于 `provenance.integrity.official_reproduction_residual`）
- **射击间隔**：由官方 `sdkTiming` 与射速模式决定，**291 个官方候选值取整后与官方整数 rpm 全部一致**（官方仅发布整数 rpm，零偏差仅在取整口径下成立）
- **状态枚举**：官方插槽规则 + 强制联动，束搜索枚举合法起枪状态，仅保留 TTK 有差异的状态；已绝版的赛季限时件（哈夫克军工改件，如 S9 链锯/格斗套件）不参与枚举，榜单为**当前赛季可达成**的配置
- **距离明细**：每状态的 0–80 m 每 10 m 采样 TTK 见 `data/榜单/<情景>.json` 的 `ttk_by_distance_ms`
- **改枪指南**：开镜时间/精校初速/后坐等不进 TTK 的维度见 [docs/改枪指南.md](docs/改枪指南.md)
- **对外数据表**：`python -m src.export` 导出至 `data/export/`，每日随榜单自动刷新；三表与 TTK 引擎**同源同真**（同一 `WeaponStateResolver` 实测口径），外部工具可据此对接两表推算任意配装
  - `weapons.json`：全部收录枪械条目完整状态
  - `parts.json`：全部配件的属性加成、弹道与伤害 profile 换挡、精校，target 附语义化键
  - `links.json`：全部「单配件 × 本体枪」对接记录，即在官方默认态上单装一件配件后的关键状态
- **榜单刷新**：仓库页 **Actions → CI → Run workflow** 手动触发，即可抓取当日行情、按需重算榜单并自动提交；官方数据更新需本地运行 `python -m src.collectors.game_data_sync` 刷新审计快照，再运行 `python tools/verify_official_reproduction.py --record-residual-conclusion` 刷新复现统计，最后用 `python tools/tables_diff.py` 审阅差异并人工合入 `data/tables/`（`data/tables/` 是运行期唯一真源）
- 价格数据：orzice 小涛查交易行当日价（2026-10-18），每日自动抓取维护（updated_at 2026-10-18）
- 枪械价格：orzice 小涛查交易行本体裸枪当日价（2026-10-18），每日自动抓取维护（updated_at 2026-10-18）
- 配件价格：orzice 小涛查交易行当日价（2026-10-18），每日自动抓取维护（updated_at 2026-10-18）；整枪价格包含该行所装配的核心配件价格（白板裸枪配件价计 0）
