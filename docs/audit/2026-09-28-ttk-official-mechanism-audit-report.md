## P0 · E[N] 与官方样本大面积脱节(影响榜单正确性)

- 实测(validation_samples.json 全量 543 点重算,~2 分钟,可复跑):
  - 逐位一致(d==0.0):**86**(15.8%)
  - |Δ| ≤ 3.6e-15:**226**(41.6%)
  - |Δ| ≤ 1e-5:**459**(84.5%)
  - **|Δ| > 1e-2:81(14.9%),最大偏差 4.5722 发**(P90 变体 `18020000002:13020000579:37210400001` @61m,官方 8.475 vs 本地 13.047,相对误差 53.9%)
- 偏差模式:81 点集中于**冲锋枪(65)与突击步枪(16)**;@26m 9/9、@61m 7/7 全失败;@0m 也有 MK4/MP7/P90 系偏 0.49–0.67 发。反解显示这些武器的官方样本与 `weapons.json` 的 `falloff_segments`/`damage_profile` **系统性脱节**(weapons.json 自 2026-09-20 提交 dbb6765 后未变,即偏差在提交时已存在)。
- **影响:远距带冲锋枪 E[N] 高估可达 54%,距离榜排序失真。**
- 与 L2 的关系:L2 证实机制规则本身与游戏公开机制一致,故该偏差**不是机制理解错误,而是武器级数据(面板/衰减段/伤害档案)与官方样本的版本脱节或反解缺口**——属上游数据层疑点,修复方向为重新同步上游补齐数据后定位。

## P2 · 验证基础设施薄弱

- test_ballistics.py 仅 11 个官方锚点(9 组 OFFICIAL + 端到端 2 点),容差 1e-4,**非全量、非逐位断言**;test_data_integrity.py 仅结构/关联/数量校验,无 E[N] 重算、无哈希校验。
- **CI(update.yml)刷新榜单但从不重跑官方样本验证——数据与验证声明可静默脱节**,本次偏差即为实证(weapons.json 提交后从未被逐位回归拦截)。
- provenance.json outputs 哈希 9/9 MATCH(规范化口径:`json.dumps(..., indent=1)` 无尾换行;字节级不同的原因是工作区 CRLF 行尾,非篡改),但**无测试固化**该哈希回归。

## L2 明细 · 外部机制对照(8 条规则 + 3 项附加)

| 规则 | 结论 | 关键佐证 |
| :-- | :-- | :-- |
| 1. 血量 100,全身共享 | 一致(社区广泛共识) | TheGamer、guides-factory、萌娘百科。单弹匣不换弹=指标口径设定,无公开资料(方法论) |
| 2. 命中部位分布随机落点 | 无公开资料(方法论;源于上游 candidateMetrics) | 社区无具体分布数值;同情景下对排序方向性影响小 |
| 3. 肉伤 = base × 弹倍率 × hitbox × 衰减 | 一致(社区广泛共识) | vgover/TapTap 攻略组(头 1.9/胸 1.0/腹 0.9/四肢 0.4,注明逐枪有异)、ali213、guides-factory |
| 4. 碎甲比例传递公式 | **一致(萌娘百科数值例与实现逐位吻合)** | 萌百例:甲伤 50/剩余耐久 30 → 引擎公式算得 28 = 萌百 12+16,完全一致。穿透系数 0%/50%/75%/100% 获五源共识 |
| 5. 覆盖由 covered_hit_areas 决定,L5/L6 含 upperArm | 一致(官方定性+社区详细规则) | 腾讯网官方新手攻略(护甲不保护全部部位/轻重甲面积差异)、萌百(肩部甲覆盖整个躯干与上臂) |
| 6. 未覆盖部位全额结算 | 一致(官方实锤级别) | 官方攻略「没有防护到的位置会吃到全额伤害」+ 多源一致 |
| 7. woundRate 不参与即时伤害 | 一致(社区广泛共识) | 萌百:流血=每 5 秒 1 点独立 DoT,不进单发结算 |
| 8. E[N]=Σ P(N>n) 数学期望 | 无公开资料(纯方法论) | 社区均用确定性公式;项目内部已与官方样本逐位对齐(部分武器除外,见 P0) |
| A. 距离衰减分段阶梯 | 一致(结构=社区共识) | thegamer「falloff 非线性、有下限」、ali213 ASH 五档阶梯。衰减段随 attr2 等比缩放=无公开资料(内部反解自洽) |
| B. 射击间隔 sdkTiming/连发节拍 | 无公开资料佐证公式(内部锚点充分) | 社区仅 60/rpm 录屏换算;「配件不能改射速」等说法与官方候选数据矛盾,判为来源错误 |
| C. 穿透矩阵 helmet/body 分槽 | health_rate 通用口径=一致(五源共识);分槽差异=无公开资料 | TheGamer+萌百方向性支持 durability_rate 阶梯 |

外部来源噪音(项目未采纳,正确):700g「护甲仅覆盖胸腹」、qieyou「配件不能改射速」、18183「超射程穿透降级/跳弹」——单一低质来源,与多数详细来源矛盾。
