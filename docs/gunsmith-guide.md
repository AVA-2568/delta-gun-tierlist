# 改枪指南（不进 TTK 的维度）

榜单只回答「击杀需要多久」。本指南说明**不影响 TTK、但影响手感与命中**的维度，
供玩家按自己的作战习惯权衡。

## 1. 开镜时间 ↔ 操控速度

面板「操控速度」经官方机制曲线直接映射为开镜时间；配件再以乘性效果叠加。

| 操控速度 | 开镜时间 |
| --: | --: |
| 35 | 480 ms |
| 40 | 428 ms |
| 45 | 383 ms |
| 50 | 350 ms |
| 55 | 321 ms |
| 58 | 302 ms |
| 60 | 290 ms |
| 65 | 257 ms |
| 70 | 230 ms |
| 75 | 213 ms |
| 80 | 195 ms |
| 90 | 160 ms |
| 100 | 130 ms |

> 实测极端改装可将开镜时间压到约 125 ms（多层乘性效果叠加），代价是据枪稳定性大幅下降。由于开镜不计入 TTK，本榜不为该取向背书。

## 2. 精校维度总览

官方精校共 12 个作用目标。**没有任何一个改变期望击杀发数或射击间隔**，
因此精校不影响 TTK 排名——这是把它交给玩家自行调校的原因。

| 精校作用目标 | 含义 | 影响 |
| :-- | :-- | :-- |
| `GAiming_ADSTime` | 开镜时间：举枪速度，影响交战时先手的快慢 | 227 处 |
| `GGunkickRandom` | 枪口随机抖动：连发时枪口的随机跳动，影响弹着散布 | 172 处 |
| `GGunkickSpring` | 枪口回弹：后坐后的复位速度，影响控枪节奏 | 172 处 |
| `GMovement_ADSSpeed` | 开镜移速：开镜状态下的移动速度 | 141 处 |
| `GRecoil_V` | 垂直后坐：枪口上抬幅度 | 114 处 |
| `GRecoil_H` | 水平后坐：枪口左右漂移幅度 | 114 处 |
| `GBullet_Velocity` | 枪口初速：弹丸飞行速度，影响提前量与远距命中 | 109 处 |
| `GBreathScale` | 呼吸晃动：据枪时准星的呼吸漂移 | 98 处 |
| `AimMoveGunSway` | 移动据枪晃动：移动中开镜的准星稳定性 | 55 处 |
| `ScopeCameraTuneDistance` | 镜距：瞄准镜的出瞳距离 | 41 处 |
| `ScopeZoomTuneRate` | 缩放倍率：瞄准镜倍率微调 | 41 处 |
| `ParallelBulletAimOffsetCm` | 并行弹道偏移：多管/并行枪管的弹着偏移 | 1 处 |

## 3. 配件层面确实影响 TTK 的维度

配件（而非精校）可通过以下规则目标改变 TTK：

| 目标 | 含义 | 对 TTK 的作用 |
| :-- | :-- | :-- |
| `WeaponMainAttribute.MainAttrValues.2` | 优势射程 | 缩放伤害衰减分段 → 改变期望击杀发数 |
| `GRateOfFire` / `FireRateMode` | 射速 | 改变射击间隔 |
| `BulletFlyingId` | 弹道档案 | 改变初速与有效射程基准 |
| `AttackerValueId.DefaultDamageId` | 伤害档案 | 整体替换基础伤害/甲伤/部位倍率 |
| `ProjectileNumPerShot` | 弹丸数 | 改变单发伤害 |
