# 纯 TTK 榜单 · armor-5-ammo-4-chest-only

- **情景 ID**：`armor-5-ammo-4-chest-only`
- **护甲/弹药**：5 套 · 4 弹（头盔耐久 50 / 背心耐久 125）
- **命中分布预设**：`chest-only`
- **排序键**：距离带内平均实战 TTK（升序，越小越强）
- **稳健性列**：距离带内最差 TTK
- **TTK 定义**：`(期望击杀发数 − 1) × 射击间隔`，不含开镜时间与弹丸飞行时间

> 层级由该情景该距离带内全部武器的 TTK 分布分位数切分（前 15% → T0，15–40% → T1，40–70% → T2，其余 → T3），阈值见下方表格。
