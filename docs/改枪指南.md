# 改枪指南（不进 TTK 的维度）

榜单回答「击杀需要多久」与「这次击杀要花多少钱」。本指南说明**不影响 TTK、但影响手感与命中**的维度，
供玩家按自己的作战习惯权衡。

## 1. 开镜时间 ↔ 操控速度

面板「操控速度」经官方机制曲线直接映射为开镜时间；配件再以乘性效果叠加。

| 操控速度 | 开镜时间 |
| --: | --: |
| 35 | 480 ms |
| 40 | 428 ms |
| 45 | 383 ms |
| 50 | 350 ms |
| 55 | 321 ms |
| 58 | 302 ms |
| 60 | 290 ms |
| 65 | 257 ms |
| 70 | 230 ms |
| 75 | 213 ms |
| 80 | 195 ms |
| 90 | 160 ms |
| 100 | 130 ms |

> 实测极端改装可将开镜时间压到约 125 ms（多层乘性效果叠加），代价是据枪稳定性大幅下降。由于开镜不计入 TTK，本榜不为该取向背书。

## 2. 精校维度总览

官方精校共 12 个作用目标。除初速外**没有任何一个改变期望击杀发数或射击间隔**；
初速精校（`GBullet_Velocity`）通过弹丸飞行时间直接进入 TTK（见 2.1），
其余均为手感维度——这是把精校交给玩家自行调校的原因。

| 精校作用目标 | 含义 | 影响 |
| :-- | :-- | :-- |
| `GAiming_ADSTime` | 开镜时间：举枪速度，影响交战时先手的快慢 | 295 处 |
| `GGunkickRandom` | 枪口随机抖动：连发时枪口的随机跳动，影响弹着散布 | 228 处 |
| `GGunkickSpring` | 枪口回弹：后坐后的复位速度，影响控枪节奏 | 228 处 |
| `GMovement_ADSSpeed` | 开镜移速：开镜状态下的移动速度 | 188 处 |
| `GBullet_Velocity` | 枪口初速：弹丸飞行速度，影响提前量与远距命中 | 155 处 |
| `GRecoil_V` | 垂直后坐：枪口上抬幅度 | 135 处 |
| `GRecoil_H` | 水平后坐：枪口左右漂移幅度 | 135 处 |
| `GBreathScale` | 呼吸晃动：据枪时准星的呼吸漂移 | 120 处 |
| `AimMoveGunSway` | 移动据枪晃动：移动中开镜的准星稳定性 | 67 处 |
| `ScopeCameraTuneDistance` | 镜距：瞄准镜的出瞳距离 | 44 处 |
| `ScopeZoomTuneRate` | 缩放倍率：瞄准镜倍率微调 | 44 处 |
| `ParallelBulletAimOffsetCm` | 并行弹道偏移：多管/并行枪管的弹着偏移 | 1 处 |

### 2.1 枪管"长度"精校：初速 ±9% 怎么取舍

枪管精校的"长度"滑块官方联动就两项：**初速 ±9%** 与**开镜时间 ∓3%**
（拉负换开镜更快，拉正初速更高），不联动射程、伤害、射速。

本榜 TTK 计入弹丸飞行时间（距离 ÷ 初速；三角洲弹道无下坠，初速只决定
"多快到达"）。初速精校因此有真实的 TTK 代价/收益，按**配装后的合成初速**
查下表（-9% 档的 TTK 恶化量；+9% 反向等量收益）：

| 配装初速 | 近距 22.5m | 中距 40m | 远距 65m | 远距 80m |
| --: | --: | --: | --: | --: |
| 350 m/s | 6.4 ms | 11.3 ms | 18.4 ms | 22.6 ms |
| 450 m/s | 4.9 ms | 8.8 ms | 14.3 ms | 17.6 ms |
| 550 m/s | 4.0 ms | 7.2 ms | 11.7 ms | 14.4 ms |
| 650 m/s | 3.4 ms | 6.1 ms | 9.9 ms | 12.2 ms |
| 750 m/s | 3.0 ms | 5.3 ms | 8.6 ms | 10.5 ms |
| 850 m/s | 2.6 ms | 4.7 ms | 7.6 ms | 9.3 ms |
| 950 m/s | 2.3 ms | 4.2 ms | 6.8 ms | 8.3 ms |
| 1050 m/s | 2.1 ms | 3.8 ms | 6.1 ms | 7.5 ms |

**判定线**（-9% 的 TTK 代价 = 换来的开镜收益 11 ms 处为平衡点；低于平衡初速
只建议正拉）：

| 用途距离 | 平衡初速 | 低于它 |
| :-- | --: | :-- |
| 近距（15–30 m） | 202 m/s | 全库枪械均在之上——纯数值上近距拉负不亏 |
| 中距（30–50 m） | 360 m/s | 正拉 |
| 远距（65 m） | 584 m/s | 正拉 |
| 远距（80 m） | 722 m/s | 正拉 |

实践口诀：**贴脸枪拉负换开镜很划算（TTK 代价 ≤6 ms 换开镜快 11 ms）；
中远距对枪线拉满 +9%**（初速就是命中速度）。注意本榜 TTK 用原始初速
（精校不改变榜面数字），本表为游戏内实战参考。

## 3. 配件层面确实影响 TTK 的维度

配件（而非精校）可通过以下规则目标改变 TTK：

| 目标 | 含义 | 对 TTK 的作用 |
| :-- | :-- | :-- |
| `WeaponMainAttribute.MainAttrValues.2` | 优势射程 | 缩放伤害衰减分段 → 改变期望击杀发数 |
| `GRateOfFire` / `FireRateMode` | 射速 | 改变射击间隔 |
| `BulletFlyingId` | 弹道档案 | 改变初速与有效射程基准 |
| `AttackerValueId.DefaultDamageId` | 伤害档案 | 整体替换基础伤害/甲伤/部位倍率 |
| `ProjectileNumPerShot` | 弹丸数 | 改变单发伤害 |
