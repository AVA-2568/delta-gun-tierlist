>
> - **排序键**：带内平均实战 TTK（`首发扳机延迟 + 击发时刻 + 弹丸飞行时间`）
> - **口径明细**：首发扳机延迟取官方 `sdkTiming.fireDelayTime`，配件可经 `FireDelayTime` 覆盖（S12「移除扳机延迟」件将其置 0）。击发时刻：单发/全自动为 `(期望击杀发数 − 1) × 射击间隔`；连发按官方 `sdkTiming` 节拍；多弹丸按扣动扳机发数。飞行时间：`距离 / 原始初速`（不含精校修正）。
> - **层级**：带内**每把枪最优配置**的 TTK 分位数切分（前 15% → T0，15–40% → T1，40–70% → T2，其余 → T3）
> - **收录范围**：只发布 T0 / T1 —— T0 共 10 行、T1 共 17 行，均全列；T2 / T3 仅参与层级阈值计算，不发布
> - **排名连续性**：未列出的行，排名均在本表末行之后；# 列为全量排名
> - **弹药口径**：3/4/5 级弹同榜，每行自带所配弹药与单发价（当日无行情显示 —）；穿深不影响腿部伤害，跨等级按 TTK 与击杀成本直接比较
> - **层级阈值**：T0 ≤ 622.5 ms / T1 ≤ 727.2 ms / T2 ≤ 881.8 ms / T3 = 其余
