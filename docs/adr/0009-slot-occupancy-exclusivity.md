# ADR-0009：配装必须遵守官方「额外占用槽位」（extra_occupancy）

- 状态：已接受
- 日期：2026-10-19
- 决策人：YH
- 影响面：`src/engine/weapon_state.py`、`src/engine/loadout.py`、`src/export.py`、
  `tests/test_loadout.py`、`data/榜单/*`、`docs/榜单/*`、`data/export/*`

## 背景

官方 `assembly.extraOccupancy` 为每个配件声明 `occupiedSocketIds`：装配该件后，
除自身安装槽位外**同时被占用**的槽位。语义是「一体式/组合件自带这些位置上的组件」，
典型：

| 配件 | 安装槽位 | 额外占用 | 含义 |
| :-- | --: | :-- | :-- |
| 汤姆逊一体冲锋枪管 13020000608 | 2 | 4, 38 | 自带护木，占死护木位 |
| 汤姆逊先进枪身系统 13050000410 | 37 | 3, 4 | 自带枪托与护木 |
| 93R HVK鼬鼠冲锋枪套件 13050000427 | 4 | 2, 6, 11, 18, 5 | 整枪改造：自带枪管/枪口/瞄具/弹匣 |
| MP5SD特勤一体消音枪管 13020000474 | 2 | 4, 6 | 自带消音器 |

采集层已把该字段固化进 `data/tables` / `data/game` 的 `extra_occupancy`，但引擎
从未消费。由此产生两处偏差：

1. **互斥件同时装配**（非法状态）：汤姆逊「一体冲锋枪管 + 先进枪身系统」、
   93R「HVK鼬鼠套件 + 远射超长枪管 + 冲锋枪回声消音器」进入榜单，最高排到
   护甲4弹药4·近距第 13 名（T0）。共 56 条榜单记录非法。
2. **内置件被覆盖后仍计入**：装一体式件时原厂内置件未卸下，其效果继续作用于
   实机状态（QJB201 獠牙短枪管的默认枪管、汤姆逊变体的枪托/护木）。

官方 291 条 `reference_candidates` 反证了口径：**可选件互斥 0 处**，仅 30 处
「可选件覆盖内部件」——后者是正常装法，前者在官方的合法配装里从不出现。

## 决策

1. **合成层卸下被覆盖的内部件**：`build_loadout` 按 `extra_occupancy` 移除
   占用集合覆盖到的内部件（`selectable=false`）。覆盖的可选件不在合成层静默处理
   ——那属于非法配装，应被拦截而非降级。
2. **枚举层拒绝互斥候选**：`LoadoutSolver` 展开选项时，候选件与已装件的
   「自身槽位 ∪ 额外占用」相交则不生成该分支；对方是内部件时不算冲突（由
   合成层卸下）。典型：汤姆逊「精工长枪管 + 先进枪身系统」合法（内置护木被替换），
   「一体冲锋枪管 + 先进枪身系统」非法（两个可选件争抢护木位）。
3. **展示差量取自实际装配**：榜单行的 `loadout` 用 `WeaponState` 的最终装配结果
   与默认件求差，而不是求解器请求的差量——被一体式件替换掉的内置件不再出现在
   配装描述里。
4. **口径公开**：`data/export/parts.json` 增加 `occupied_socket_ids`，外部工具
   可据此自行判定互斥（同一配件在全部武器的声明一致，已核验 41 个配件零分歧）。
5. **回归护栏**：`tests/test_loadout.py` 钉死三条——内部件必须卸下、汤姆逊互斥件
   不得同入枚举、官方候选不得出现可选件互斥。

## 后果

- 汤姆逊与 93R 的状态行失效，需全量重算并重渲染；93R 的枪管/消音器加成不再叠加，
  TTK 变化幅度最大。
- 枚举空间略缩（互斥分支被剪），运行时间不变或更短。
- 其他枪的数值仅在「带额外占用的可选件」被选中时变化（MP5/QJB201 当前未触发）。
- 新增审计脚本 `tools/audit_slot_occupancy.py`（`ranking` / `space` / `official`
  三种模式），CI 之外的本地核查入口。

## 否决的方案

| 方案 | 否决理由 |
| :-- | :-- |
| 仅在合成层静默丢弃冲突的后来者 | 会把非法配装降级成合法状态继续计分，榜单仍出错 |
| 只在枚举层拦截、不清理内置件 | 内置件效果继续计入，TTK 数值失真（QJB201 案例） |
| 把 `occupiedSocketIds` 当作纯展示字段导出 | 榜单仍需人工核对，无法从机制上杜绝复发 |
