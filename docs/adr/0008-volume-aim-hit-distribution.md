# ADR-0008：实战情景改用体积预瞄命中分布（`volume-aim`）

- 状态：已接受
- 日期：2026-10-19
- 决策人：YH
- 影响面：`data/tables/scenarios.json`、`src/pipeline.py`、`src/renderers/ttk_report.py`、
  `tools/derive_hit_probabilities.py`、README 口径与情景索引

## 背景

官方 `default` 预设的命中分布为：头 17.24% / 胸 30.46% / 腹 18.97% /
上臂 12.00% / 前臂 7.11% / 大腿 7.11% / 小腿 7.11%（腿合计 14.22%）。

与人体正面轮廓相比，该分布把约 **18 个百分点**的命中从腿挪给了头与手臂：

| 部位 | 官方 default | 体积基准 | 偏差 |
| :-- | --: | --: | --: |
| 头 | 17.24% | 8.10% | +9.14 |
| 上臂 + 前臂 | 19.11% | 10.00% | +9.11 |
| 大腿 + 小腿 | 14.22% | 32.20% | −17.98 |

实战交战的准星落在胸腹而非全身均匀分布，官方预设既不是体积口径也不是预瞄口径，
用它计算期望击杀发数会系统性放大头部与手臂的作用。实测单因素影响（0 m、5 级弹、护甲 5）：

- 头 17.24% → 8.10%：TTK 中位 **+31.5 ms**（SV98 单枪 +426 ms）
- 手臂 19.11% → 10.00%：TTK 中位 **−18.1 ms**（L5/L6 背心覆盖上臂，臂伤倍率仅 0.4–0.5）
- 腿 14.22% → 32.20%：TTK 中位 **+32.0 ms**

三项互相抵消，导致"排名看似稳定、数值却建立在错误结构上"。

## 决策

新增命中分布预设 `volume-aim`，用于 5 个实战情景；官方 21 个情景原样保留在
`data/tables/scenarios.json`（作对照与回归基准），但不再进入发布集合。

模型（推导脚本 `tools/derive_hit_probabilities.py`，参数全部显式）：

1. **正面轮廓**：身高 1.75 m，中线 x=0，部位按矩形区间离散化（步长 5 mm）。
2. **胸腹分界**：躯干 0.98–1.52 m 按「胸:腹 = 1:2」求解，分界 **1.348 m**——
   与剑突解剖高度（1.30–1.35 m）吻合，对应游戏内 `upperChest` 止于剑突、
   `lowerChest` 含整个腹腰段的实际划分。
3. **预瞄点**：**1.30 m**（胸腹交界，背心中央偏上）。
4. **弹着点**：以预瞄点为中心的二维高斯，σ_v = **0.28 m**、σ_h = **0.50 σ_v**
   （20 m 处垂直误差约 0.8°，横向误差为垂直的一半）。
5. **部位概率** = 该部位轮廓内的高斯质量 / 全轮廓高斯质量。

产物：

| 部位 | 概率 |
| :-- | --: |
| 头 | 9.13% |
| 胸 | 19.68% |
| 腹 | 40.69% |
| 上臂 | 14.19% |
| 前臂 | 5.38% |
| 大腿 | 10.73% |
| 小腿 | 0.20% |

聚合：头 9.13% / 躯干 60.37% / 手臂 19.57% / 腿 10.93%。

参数取值的交叉校验：

- 手臂合计 19.57% 与官方 default 的 19.11% 独立吻合（官方预设虽整体失真，
  但手臂口径与几何+散布模型一致）；
- 头部 9.13% 介于体积基准 8.10% 与官方 17.24% 之间，接近体积上限；
- 小腿 0.20%——预瞄在胸腹时，膝盖以下几乎不可能被命中，符合实战。

## 后果

- 5 个实战情景的 `scenario_id` 增加 `-volume` 后缀，`probability_preset = volume-aim`；
  文档落盘名保持「护甲X弹药Y-实战」，README 链接不变。
- 官方 `default` / `center` / `chest-only` 情景不再发布，但保留在表内：
  `tools/migrate_tables.py --check` 仍可对账，官方复现测试继续以
  `data/game/scenarios.json` 为基准，不受影响。
- TTK 绝对量上移：全量重算后，主榜（护甲5弹药5）267 个共同状态的 ΔTTK 中位为
  贴脸 **+22.4 ms**、近距 +22.4 ms、中距 +24.0 ms、远距 +25.0 ms；T0 阈值贴脸
  344.7 → 376.6 ms。**排序结论稳健，变化在绝对数值与个别武器**：中距 M700 掉出前 5
  （头部权重下降对狙击最不利），SR25 补位；贴脸与近距前 5 仍全部为 MK4。
- 击杀成本随期望发数同步上移（成本 = 期望发数 × 单发价），整枪价格不变。
- 本次全量重算同时让仓库产物与当前引擎的配装枚举对齐：此前提交 `5088663`
  修复枚举完整性（单选项插槽、解锁型提供者），但仓库内榜单未跟进。重算后 6 个情景的
  状态行数由 328–1020 行增至 649–1908 行；修脚榜 1020 个共同状态的 TTK **逐一未变**，
  新增行均为此前漏枚举的合法状态。`data/榜单/` 体积由约 6.5 MB 增至 13 MB。
- 已知限制：模型不含掩体遮挡、蹲伏姿态与目标移动，也未区分左右手；
  腿部已通过预瞄权重压低，若后续需要表达掩体，应新增显式参数而非改本模型。
