# ADR-0003：榜单文档展示规则补充（排名连续性）

- 状态：已接受
- 日期：2026-10-18
- 决策人：YH
- 关联：ADR-0002

## 决策

距离榜中未展示的行，其排名**必然在本表末行之后**。理由：分层按带内 TTK 单调切分，
T0 占据排名最前的一段，T1 紧随其后，T2/T3 再往后；因此展示行不会出现空号。

页头删除「空号即其间存在未列出行」的旧表述，改为：

> 未列出的行，排名均在本表末行之后；完整数据见 `data/榜单/<情景>.json`。

## 后果

- 渲染层不再输出「空号」提示。
- 测试断言：展示行的 rank 连续递增，无跳号。
