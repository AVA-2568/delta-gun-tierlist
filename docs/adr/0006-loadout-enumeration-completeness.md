# ADR-0006：配装枚举必须覆盖「单选项插槽」与「解锁型提供者」

- 状态：已接受
- 日期：2026-10-18
- 决策人：YH
- 影响面：`src/engine/loadout.py`、`tests/test_loadout.py`、`data/榜单/*`、`docs/榜单/*`

## 背景

`build_socket_specs` 原先用 `len(options) <= 1: continue` 剪枝，同时
`_prune_options` 只保留**自身直接改 TTK** 的配件。两条规则叠加导致合法的最优配装
被系统性漏掉：

1. **单选项插槽**：唯一选项不是默认件、且改 TTK 时，玩家仍可选择它；
   但插槽被整槽跳过。典型：MCX-LT 装焰魂枪管（13020000573）后，耦合规则强制
   挂载 376 护木，376 只暴露一个 socket 51（SUR 隔热外罩 13410000002）。
   SUR 的 `GRateOfFire` 为 -3.4%，实测 5-5 情景贴脸 TTK 由 371.59 ms 降到
   359.52 ms（-3.2%），但从未进入枚举。
2. **解锁型提供者**：配件本身不改 TTK，却解锁改 TTK 的插入式插槽。
   典型：QJB201 护木解锁高速/稳固导气箍（射速差 36 ms）；M700 的 S11
   HVK 旋风枪身系统解锁强化导气。它们被当作「不影响 TTK」剪掉，导致
   被解锁的 TTK 状态不可达。

数据侧已核对：`data/tables/parts/` 共 1141 条、145 条 TTK 相关件，武器/配件
引用无悬空、TTK 效果无空值。缺的不是数据，而是枚举覆盖。

## 决策

1. **单选项也要枚举**：剪枝后选项满足「多于一个」或「唯一选项不是默认件」
   即纳入；唯一选项就是默认件时跳过（默认态已包含）。
2. **解锁型提供者纳入枚举**：若某提供者能暴露默认装法拿不到的**非默认
   TTK 选项**，则该提供者参与枚举。已由默认装法覆盖的提供者不纳入
   （避免把所有枪管都当有效提供者、放大搜索空间）；`forced` 耦合件不纳入
   （由耦合规则自动挂载，不需要作为自由选项搜索）。
3. **赛季限时件继续人工排除**：上游只含配件定义、不含获取渠道。S10「裂变」
   的复合弓 HVK 速射箭匣（13120000381，改射速/优势射程）与 SVCH 凌风并联
   弹匣（13120000379）已加入 `EXCLUDED_PART_IDS`；S11 的 HVK 鼬鼠套件、
   旋风枪身系统与强化导气属于当前赛季，保留在枚举内。官方变体同样受该清单
   约束：变体件命中 `EXCLUDED_PART_IDS` 时整行不出榜（ASh-12 HVK 双发枪管）。

## 后果

- MCX-LT 焰魂 + SUR、QJB201 导气箍、M700 S11 HVK 套件等合法状态进入榜单。
- 受影响武器的 TTK 与排名会变化，必须全量重算并重渲染；不是「零变化」改动。
- 新增测试：单选项非默认 TTK 件必须枚举；已绝版 S10 件不得进入枚举。
- 束搜索空间仅增加真正解锁新 TTK 选项的提供者（全库仅 G3/PTR-32/M700
  三把枪触发），运行时间增量可控。

## 否决的方案

| 方案 | 否决理由 |
| :-- | :-- |
| 继续跳过单选项插槽 | 会漏掉 SUR 这类合法且影响 TTK 的选择，榜单最优状态不成立 |
| 枚举所有插槽的所有选项 | 组合爆炸（未剪枝约 6.1e21），且绝大多数选项与 TTK 无关 |
| 把所有提供者都纳入枚举 | 各枪枪管会全部展开，搜索空间放大一个量级，收益仅限少数解锁件 |
